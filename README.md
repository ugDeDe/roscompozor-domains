# roscompozor-domains

Актуальные домены сайта [roscompozor](https://roscompozor.site): пробы роскомпозора читают отсюда, на какой адрес подключаться, когда домен меняется.

`domains.json` подписан ключом Ed25519 проекта; пробы проверяют подпись и не принимают неподписанный, изменённый или более старый список. Править файл вручную бесполезно — он перестанет проходить проверку. Новый список делается командой `roscompozor-domains sign` из основного репозитория.
